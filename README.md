# 📝 Feedback Collector App

A simple Flask web application that collects user feedback through a form and displays all feedback entries on a separate page. Perfect for learning Flask basics like routing, form handling, file I/O, and templating.

---

## 🚀 Features

- Submit feedback with name, email, and message
- Store feedback in a JSON file
- View all submitted feedback on a dashboard
- Minimal and clean UI using basic HTML templates

---

## 🛠️ Tech Stack

- 🐍 Python
- 🔥 Flask
- 🧾 HTML (Jinja2 templates)
- 🗃️ JSON for storage
